# 拾形 SHAPEFOLIO

**好设计，值得拾起。** 一个原创中文网站设计灵感库，使用原生 HTML / CSS / JavaScript 构建。零生产依赖，无需账号或后端，兼容 GitHub Pages 项目子路径。

## 内容与功能

- 12 个真实网站案例，附官方链接、编辑设计笔记与学习提示
- 原创 CSS 艺术封面，清晰标注为视觉演绎，非官网截图
- 分类筛选、即时关键词搜索、名称排序、组合过滤及空状态
- 收藏仅保存在当前浏览器 localStorage，刷新后仍保留
- 原生 dialog 详情弹窗，Escape 关闭，键盘焦点约束与返回
- 响应式双栏/单栏布局、可见焦点、跳转链接、减少动态效果支持
- 无第三方字体、图像请求、追踪脚本或复制的品牌素材

## 本地运行

需要 Node.js 20 或更新版本。不需要安装依赖。

```sh
npm run dev
# 打开 http://localhost:4173
npm test
npm run build
```

输出目录为 `dist/`。可将其部署到任意静态托管服务。开发服务器为本地预览用途，不应用于生产托管。

## GitHub Pages

1. 将本项目放入公开仓库。
2. 执行 `npm test && npm run build`。
3. 将 `dist/` 作为 Pages 的部署产物；也可把 dist 内容放在单独发布分支根目录。
4. 仓库 Settings → Pages 中选择对应分支或 GitHub Actions。

全部资源引用均为相对路径，不需要修改站点基路径。收藏作用域为浏览器来源；同一 GitHub Pages 来源上的本项目副本会共享相同的收藏键。浏览器隐私模式、存储禁用或清除站点数据可能使收藏无法持久化；失败时页面会提示。

## 编辑案例

在 `src/data.js` 的 `cases` 数组中添加或修改案例。保留唯一 id、名称、分类、标签、HTTPS 原站、笔记、学习提示、封面文案与样式名；在 `src/styles.css` 中添加对应原创封面样式。若增加案例数量，请同步首页静态介绍与测试中的数量。

## 项目结构

```text
index.html         语义化页面与对话框
src/data.js        案例数据与纯筛选函数
src/app.js         交互、本地收藏、详情展示
src/styles.css     原创视觉系统与响应式布局
scripts/           无依赖构建与预览服务器
tests/             Node 原生单元测试
ATTRIBUTION.md     来源、版权与隐私说明
```

## 验证与许可

`npm test` 验证数据完整性、搜索、分类、收藏组合、排序不变性及相对资源路径；不替代真实浏览器的可访问性或多设备人工测试。
